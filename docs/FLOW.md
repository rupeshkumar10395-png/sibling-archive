# Product flow

```text
Homepage
  ↓
Create archive
  ↓
Creator workspace
  ↓
Add memories
  ↓
Invite sibling
  ↓
Receiver opens private invite
  ↓
Receiver creates/joins account
  ↓
Receiver contributes independently
  ↓
Both sides ready
  ↓
Media processing complete
  ↓
Publish transaction
  ↓
/archive/:slug
```

The final archive is a read model assembled from database-backed memory records, not a hard-coded HTML document.
